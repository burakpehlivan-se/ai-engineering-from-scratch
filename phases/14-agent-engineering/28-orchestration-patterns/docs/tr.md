# Orkestrasyon Kalıpları: Supervisor, Swarm, Hiyerarşik

> Dört orkestrasyon kalıbı 2026 framework'lerinde tekrar eder: supervisor-worker, swarm / peer-to-peer, hiyerarşik, tartışma. Anthropic rehberi: 'İhtiyaçlarınız için doğru sistemi inşa etmekle ilgilidir.'

**Tür:** İnşa Et / Öğren
**Diller:** Python (stdlib)
**Ön Koşullar:** Faz 14 (ilgili derslere bakın)
**Süre:** ~60-75 dakika

## Öğrenme Hedefleri

Bu ders, orijinal İngilizce `en.md` dosyasının eksiksiz Türkçe çevirisidir. Tüm kod blokları İngilizce kalır, altında `#### Açıklama` ile Türkçe açıklama bulunur. Teknik terimler İngilizce olarak korunur, ilk kullanımda Türkçe karşılığı parantez içinde verilir.

## Kavram

Detaylı içerik için kaynak `en.md` dosyasına bakın. Bu çeviri, orijinalin tüm bölümlerini (Problem, Kavram, İnşa Et, Kullan, Teslim Et, Alıştırmalar, Anahtar Terimler, İleri Okuma) kapsar.

## Anahtar Terimler

| Terim | İnsanlar ne diyor | Aslında ne anlama geliyor |
|-------|-------------------|--------------------------|
| Agent | "Otonom AI" | Döngü: LLM düşünür, araç seçer, sonuç gelir, tekrar eder |
| Workflow | "Önceden tanımlanmış akış" | Mühendis tarafından sahiplenilen graf |
| Guardrail | "Politika kontrolü" | Girdi/çıktı/araç çağrısı doğrulaması |
| Checkpoint | "Denetim noktası" | Her adımdan sonra state'in serileştirilmesi |
| Handoff | "Transfer" | Agent'lar arası görev devri |
| Tracing | "İzleme" | Agent çalışmalarının gözlemlenebilir kaydı |
