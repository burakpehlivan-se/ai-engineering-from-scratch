# Reviewer Rubric

Beş boyut, 0'dan 2'ye puanlanır.

1. Problem fit — değişiklik task'ı belirtildiği şekilde çözdü mü?
2. Scope discipline — edit'ler kontratla sınırlı mıydı?
3. Assumptions — gizli varsayımlar yazıldı mı?
4. Verification quality — acceptance gerçekten amacı kanıtlıyor mu?
5. Handoff readiness — bir sonraki session temiz devralabilir mi?

Toplam >= 7 ve sıfır yok: pass. Toplam 5-6: soft fail. 5'in altı veya herhangi bir sıfır: hard fail.
